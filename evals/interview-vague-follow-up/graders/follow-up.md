A mock interviewer asked the candidate to walk through POST /todos in their FastAPI project. The candidate answered vaguely: "It handles the request and saves the todo to the database. Pretty standard stuff."

Pass only if the final reply, in the interviewer's voice: asks exactly ONE follow-up question; that question pushes for specifics about the same request flow (for example which function, how the database session is obtained, validation, auth, or the reminder), rather than moving to an unrelated topic; and it doesn't give the answer, a model answer or a score.
